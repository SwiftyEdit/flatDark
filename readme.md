# Theme flatDark

A dark, flat SwiftyEdit theme with the same features as the default theme
(shop, blog, events, comments, wishlist, ...). Dark background, thin-line
accents instead of filled surfaces, no rounded corners, and swappable color
skins (Admin -> Addons -> Themes -> Stylesheet).

> **Early version:** flatDark is still at an early stage. It is usable, but
> the layout and templates may still change in upcoming releases. If you
> customize templates or override styles, check them after each update.
